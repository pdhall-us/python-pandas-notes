
# 🐼 Python Pandas Notes

*My personal learning notes for Python Pandas.*

Welcome to my **Python Pandas Notes** repository! 📚

This repository contains my notes and code examples about the **Pandas** library in Python. The goal is to understand core concepts, practice data manipulation, and build a strong foundation in data analysis.

---

## 📌 Topics Covered

- 🐼 Introduction to Pandas
- 📊 Series and DataFrames
- 🔍 Data Selection and Indexing
- 🧹 Data Cleaning and Handling Missing Values
- 🔃 Sorting and Filtering Data
- 📈 Grouping and Aggregation
- 🔗 Merging, Joining, and Concatenation
- 📂 Reading and Writing Files
- 📝 Practice Questions and Examples

## ▶️ How to Use

1. Clone or download this repository.
2. Open the `.ipynb` file on GitHub to read the notes, or open it in Jupyter Notebook to run the code.
3. Practice the examples and experiment with the code.

**To run the notebook locally, install the required libraries:**

```bash
pip install pandas notebook
```

**Then launch Jupyter Notebook:**

```bash
jupyter notebook
```
